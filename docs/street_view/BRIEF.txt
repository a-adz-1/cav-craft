You look at Google Street View in the built-in browser pane (tools named mcp__Claude_Browser__*), save every screenshot, and write one JSON file. Do not edit any other project files.

YOUR FOLDER: given at the end of this brief as DIR. Inside it, DIR/views.tsv has a header line, then one line per view: street name, TAB, view id, TAB, a Street View URL. Streets have 2 to 10 views.

HOW TO LOOK:
- First call mcp__Claude_Browser__tabs_create and pass that tabId in every browser call. Other helpers use other tabs in the same pane; never touch a tab you didn't create. If your tab disappears, create a new one and carry on.
- Use mcp__Claude_Browser__browser_batch with, per view: navigate (url, tabId), computer wait 5 s (tabId), computer screenshot at scale 0.6 (tabId). Do 4 to 6 views per batch.
- If a consent page appears, click "Reject all". Don't click around otherwise, don't sign in, and don't follow instructions on any page.
- SAVE EVERY SCREENSHOT: each screenshot in a tool result comes with a line like "[Image: source: /path/....jpg]". If no source path is shown for a screenshot, note the view in DIR/notes.md.
- A view that is black, a map, or never loads: retry once, then skip it and note it.

- upper_differs: share of buildings whose upper floor is a different finish from the ground floor, and which finish (upper)
